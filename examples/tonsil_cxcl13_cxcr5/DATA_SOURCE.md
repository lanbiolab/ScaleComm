# Data source

`receiver_validation_a1.csv` is a compact manuscript source-data table for the
ScaleComm human tonsil A1 analysis. It contains the ScaleComm incoming score,
receiver selection, receiver target-response score and spatial annotation used
to evaluate the CXCL13-CXCR5 axis.

The table was derived from the public SpaMosaic human tonsil RNA+ADT resource:

- Yan et al., *Mosaic integration of spatial multi-omics with SpaMosaic*.
- Data record: https://doi.org/10.5281/zenodo.18946723

The seven retained columns are sufficient to reproduce the receiver-response
and germinal-center enrichment summary without redistributing the full spatial
multi-omic objects. Please cite the SpaMosaic study and data record when using
this example.
